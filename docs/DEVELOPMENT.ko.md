# 클로드 펫

Claude Code 세션의 진행 상황을 화면 맨 위에 떠 있는 캐릭터로 보여 주는 데스크톱 펫입니다. 작업 중인 내용을 말풍선으로 보여 주고, 끝나거나 확인이 필요하면 움직임과 소리로 알립니다. 기본 펫은 매 화면마다 새로 그리는 3D 펫 **모찌 3D**이고, 코덱스 펫 압축 파일(.zip)을 넣어 펫을 추가할 수 있습니다. 화면은 한국어와 영어를 고를 수 있습니다.

## 다른 사람에게 나눠 주기

```
node tools/package.js
```

`~/.claude-pet/dist/`에 아래 묶음과 `SHA256SUMS.txt`가 생깁니다. 받는 사람은 Node.js가 없어도 됩니다.

| 묶음 | 받는 사람이 할 일 |
|---|---|
| `ClaudePet-<버전>-win-x64.zip` (약 160MB) | 압축을 풀고 `ClaudePet.exe` 실행. 처음 한 번 "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행" |
| `ClaudePet-<버전>-mac-arm64.zip` (Apple 칩), `-mac-x64.zip` (Intel) | 압축을 풀고 `Claude Pet.command`를 우클릭 → 열기 (처음 한 번) |

- 묶음 안에는 프로그램 파일 목록(`tools/package.js`의 `APP_FILES`)과 모찌 펫만 들어갑니다. 설정, 로그, 시안, 시험 파일, 이 PC의 경로가 적힌 문서는 들어가지 않습니다. 묶음마다 `README.txt`(한국어·영어)가 들어 있습니다.
- 윈도우 묶음은 이 PC의 `~/.claude-pet/runtime`에 있는 Electron을 쓰고 실행 파일 이름만 바꿉니다. 맥 묶음은 Electron 공식 릴리스(GitHub)에서 맥용 Electron을 한 번 받아 `~/.claude-pet/build-cache`에 두고, 같은 릴리스의 SHA256 목록과 맞을 때만 씁니다. Electron.app은 손대지 않고 그대로 넣습니다(서명이 깨지지 않게).
- 코드 서명이 없어서 처음 실행할 때 OS 경고가 뜹니다. 회사 보안 프로그램이 막으면 IT에 예외 등록을 요청해야 합니다.
- 나눠 줄 때 `SHA256SUMS.txt`의 값을 함께 알려 주면, 받는 사람이 같은 파일인지 확인할 수 있습니다 (윈도우: `Get-FileHash 파일.zip`, 맥: `shasum -a 256 파일.zip`).
- 맥 묶음은 만들기만 했고 맥에서 실행해 보지 않았습니다.

### GitHub에 올리기

이 폴더는 OneDrive 동기화 폴더라 git을 쓰지 않습니다. 대신 올릴 파일만 다른 폴더로 복사합니다.

```
node tools/export-github.js        # ~/claude-pet-github 를 새로 채운다 (.git은 그대로)
```

그 폴더에서 커밋하고 푸시합니다. 배포 zip은 저장소에 넣지 않고 GitHub Releases에 올립니다 (`gh release create v<버전> <zip>`). zip 내용이 바뀌면 `package.json`의 버전을 올리고 새 Release를 만듭니다 (이미 올린 Release의 파일은 바꾸지 않음).

GitHub 설명은 언어마다 `github/README.<언어>.md`에 있습니다. 영어(`README.en.md`)가 첫 페이지가 되고, 나머지는 `README.<언어>.md`로 나갑니다. 각 파일 맨 위의 `<!-- languages -->` 줄은 내보낼 때 모든 언어로 가는 단추 줄로 바뀝니다. 스크린샷은 `github/images/<언어>/`(언어별)와 `github/images/common/`(공통)에 둡니다.

**새 언어 추가**: `github/README.<언어>.md`와 `github/images/<언어>/`를 만들면 단추가 자동으로 생깁니다. 단추 이름은 `tools/export-github.js`의 `LANGUAGE_NAMES`에서 고릅니다. 내보낼 때 깨진 그림이나 링크가 있으면 멈춥니다. 펫 화면 자체에 언어를 더하려면 `i18n.js`에 그 언어 표를 넣고 `config.js`의 `LANGUAGES`에 더합니다 (배포 zip의 Chromium 언어 파일도 따라서 들어갑니다).

**맥 버전 올리기**: 맥에서 한 번 실행해 확인한 뒤, `node tools/package.js`(윈도우·맥 모두)로 같은 버전의 zip을 만들어 한 Release에 함께 올리고, 설명의 내려받기 표에서 macOS를 "준비 중"에서 받기 링크로 바꿉니다. 지금 `~/.claude-pet/dist`의 맥 zip(1.0.0)은 이후 고친 내용이 빠진 옛 파일이라 쓰지 않습니다.

### 처음 실행하면

1. 컴퓨터의 언어로 화면 언어를 정합니다 (한국어 윈도우·맥은 한국어, 그 밖은 영어). 메뉴의 "언어 / Language"나 펫 꾸미기 창에서 바꿉니다.
2. 이 PC의 Claude를 찾습니다: Claude Code 기록(`~/.claude/projects`)과 Claude 데스크톱 앱의 세션 목록. 로그인이나 비밀번호 입력은 없고, 비밀번호와 토큰은 읽지 않습니다.
3. 승인 대기 알림용 훅을 `~/.claude/settings.json`에 자동으로 등록합니다. 다른 도구의 훅은 그대로 두고, 바꾸기 전 설정을 백업합니다. 메뉴의 "승인 대기 알림 (훅)"으로 끄면 우리 훅만 지우고 다시 등록하지 않습니다.
4. 위 결과를 "클로드 펫 시작하기" 창에 보여 줍니다. 나중에 메뉴의 "연결 상태 보기…"로 다시 볼 수 있습니다.

펫은 인터넷에 연결하지 않습니다 (`tests/wiring.test.js`가 네트워크 코드가 없는지 확인합니다).

## 필요한 것 (이 폴더에서 직접 실행할 때)

- Node.js 18 이상 (윈도우와 맥 모두)
- Electron 45.5.0: 처음 실행할 때 `~/.claude-pet/runtime/`에 자동으로 설치됩니다. PC마다 한 번, 인터넷 연결이 필요합니다.

OS마다 실행 파일이 달라서 Electron은 OneDrive 폴더가 아닌 홈 폴더에 둡니다. 이 폴더에서 `npm install`을 할 필요는 없습니다.

## 실행

| OS | 방법 |
|---|---|
| 윈도우 | `펫 실행.bat` 더블클릭 |
| 맥 | `펫 실행.command` 더블클릭 (처음 한 번 터미널에서 `chmod +x "펫 실행.command"`) |
| 공통 | 이 폴더에서 `node launch.js` |

미리보기는 `node launch.js --demo`로 볼 수 있습니다. 가짜 상태를 4초마다 바꿔 가며 보여 줍니다.

## 쓰는 법

- **펫 드래그**: 펫을 옮깁니다. 위치는 기억됩니다. 끌어서 옮길 때는 클릭으로 치지 않습니다.
- **펫 클릭**: Claude 앱을 엽니다. 진행 중인 세션이 있으면 그 세션을, 없으면 마지막에 쓴 세션을 엽니다.
- **말풍선 클릭**: 말풍선에 표시된 세션을 Claude 앱에서 엽니다.
- **말풍선의 `+N` 클릭**: 세션 목록을 여닫습니다.
- **목록의 줄 클릭**: 고른 세션을 Claude 앱에서 엽니다.
- **우클릭**: 메뉴가 나옵니다.
- **알림 영역 아이콘**: 펫이 떠 있는 동안 작업 표시줄의 알림 영역(맥은 메뉴 막대)에 펫 얼굴 아이콘이 나옵니다. 마우스를 올리면 지금 상태가 보이고, 누르면 우클릭 메뉴와 같은 메뉴가 나옵니다. 3D 펫은 고른 색을 따라갑니다. 윈도우는 새 아이콘을 숨겨진 아이콘 목록(^) 안에 넣으므로, 시계 옆에 항상 보이게 하려면 목록에서 끌어내세요.

세션 열기는 Claude 데스크톱 앱에서 만든 세션에만 정확히 동작합니다. 터미널이나 IDE에서 돌린 세션은 앱에 대응하는 세션이 없어서 Claude 앱의 코드 탭 첫 화면만 띄웁니다.

### 우클릭 메뉴

| 항목 | 하는 일 |
|---|---|
| 펫 꾸미기… | 펫 고르기, 펫 추가(압축 파일), 크기, 3D 펫 색상, 펫 목록 새로 고침을 모은 창을 엽니다 (아래 "펫 꾸미기 창" 참고) |
| 세션 목록 보기 | 진행 중인 세션 목록을 여닫습니다 |
| 완료 표시 지우기 | "다 됐어요"와 오류 표시를 세션을 열지 않고 지웁니다 |
| 말풍선 보이기, 알림음 | 켜고 끕니다 |
| 부드러운 움직임 | 이미지 펫: 프레임이 바뀔 때 앞뒤 그림을 짧게 겹쳐 넘기고, 완료 점프·끌기·놓기에 탄력을 줍니다. 3D 펫: 동작은 원래 끊김 없이 이어지고, 이 항목은 누를 때 눌림·끌 때 기울임·완료 때 한 번 더 뛰는 탄력만 켜고 끕니다 |
| 컴퓨터 켤 때 자동 실행 | 로그인할 때 펫이 자동으로 뜨게 합니다 |
| 승인 대기 알림 (훅) | 훅을 켜고 끕니다. 끄면 우리 훅만 지웁니다 |
| 언어 / Language | 한국어, English |
| 연결 상태 보기… | 처음 실행 창(Claude를 찾은 결과, 훅 상태)을 다시 엽니다 |
| 종료 | 펫을 끕니다 |

실행 파일을 한 번 더 실행하면 새로 뜨지 않고 펫 꾸미기 창을 띄웁니다.

펫을 화면 가장자리에 붙여도 말풍선은 화면 안쪽으로 밀려서 표시됩니다. 화면 맨 위 근처에서는 말풍선이 펫 아래에 나옵니다.

### 펫 꾸미기 창

메뉴의 "펫 꾸미기…"를 누르면 따로 뜨는 창입니다. 펫의 겉모습에 관한 것은 모두 여기서 바꿉니다.

- **펫 목록(왼쪽)**: 찾은 펫이 그림과 함께 나옵니다. 누르면 오른쪽 미리보기만 바뀌고, 실제 펫은 그대로입니다. 지금 쓰는 펫에는 "사용 중"이 붙습니다. 규격에 맞지 않는 펫은 "불러올 수 없음"으로 나오고, 누르면 사유가 보입니다.
- **압축 파일에서 펫 추가**: 목록 마지막 칸을 누르고 코덱스 펫 압축 파일(.zip)을 고릅니다. 창에 .zip을 끌어다 놓아도 됩니다. 여러 개를 한 번에 넣을 수 있고, 다 되면 새 펫이 골라진 채로 미리보기에 나옵니다. [codex-pets.net](https://codex-pets.net)에서 받은 파일을 그대로 넣으면 됩니다.
- **가져온 펫 지우기**: 가져온 펫 카드의 ×를 누릅니다 (한 번 묻습니다). 함께 들어 있는 모찌 3D는 지울 수 없습니다.
- **새로 고침**: 펫 폴더를 다시 읽습니다.
- **언어**: 목록 아래에서 한국어·English를 고릅니다.
- **미리보기(오른쪽 위)**: 고른 펫이 지금 크기와 색으로 움직입니다. "상태" 줄(대기·작업 중·확인 필요·완료·오류)은 상태별 모습을, "동작" 줄(인사·점프·오른쪽 끌기·왼쪽 끌기·둘러보기)은 그 동작 하나만 반복해서 보여 줍니다. 두 줄로 펫의 동작 9개를 모두 볼 수 있습니다. 대기 상태에서 창 안에 마우스를 움직이면 펫이 커서 쪽을 바라봅니다.
- **이 펫으로 바꾸기**: 미리 보던 펫을 실제 펫으로 씁니다. 이미지 펫과 3D 펫 사이를 오갈 때는 펫과 이 창이 1~2초 사라졌다 다시 뜹니다.
- **크기**: 25%에서 120%까지 5% 단위로 바꿉니다. 움직이는 대로 실제 펫에 바로 반영되고 저장됩니다.
- **색상**: 3D 펫의 몸 색입니다. 준비된 색 10개 중에서 고르거나, 사각형(선명함·밝기)과 띠(색상)에서 직접 고릅니다. "원래 색"을 누르면 되돌아갑니다. 고르는 대로 바로 반영되고 저장됩니다. 이미지 펫을 고른 동안에는 쓸 수 없습니다.

창은 Esc나 "닫기"로 닫습니다. 닫아도 펫은 그대로 떠 있습니다.

### 자동 실행

우클릭 메뉴의 "컴퓨터 켤 때 자동 실행"을 켜면 PC마다 아래 위치에 등록됩니다. 다시 누르면 지워집니다.

- 윈도우: 현재 사용자 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 `ClaudePet` 값
- 맥: `~/Library/LaunchAgents/com.claude-pet.autostart.plist`

프로젝트 폴더를 옮기면 자동 실행을 껐다 다시 켜야 합니다. `node autostart.js --status`로 상태를 볼 수 있습니다.

윈도우에서는 이 값을 윈도우 서비스(WMI)를 거쳐 읽고 씁니다. Claude 데스크톱 앱처럼 스토어에서 설치한 앱 안에서 펫을 띄우면, 평범한 방법으로 쓴 설정이 그 앱만의 격리된 영역에 들어가 로그인 때 실행되지 않기 때문입니다. 켜고 끌 때 0.5~1초쯤 걸립니다.

## 상태

| 상태 | 언제 | 재생하는 행 |
|---|---|---|
| 대기 | 진행 중인 세션이 없을 때 | `idle` (v2 펫은 커서 쪽을 바라봄) |
| 작업 중 | Claude가 생각하거나 도구를 쓰는 중 | `running` |
| 확인 필요 | 승인이나 답을 기다릴 때 | `waiting` |
| 완료 | 턴이 끝났을 때. 펫에서 그 세션을 열거나, Claude 앱에서 그 세션을 직접 열어 보거나, "완료 표시 지우기"를 누를 때까지 유지 (최대 30분) | `jumping` 한 번 뒤 `review` |
| 오류 | API 오류로 멈췄을 때 | `failed` |

드래그 중에는 `running-right`, `running-left`를, 시작할 때와 클릭할 때는 `waving`을 재생합니다. 여러 세션이 겹치면 확인 필요, 오류, 완료, 작업 중 순으로 하나를 대표로 보여 줍니다.

## 3D 펫

펫 꾸미기 창에서 **모찌 3D**를 골라 "이 펫으로 바꾸기"를 누르면 그림 시트 대신 3D로 그립니다.

- **동작**: 원본 시트의 프레임 하나하나를 3D 자세로 맞춰 두고 그 사이를 이어서 재생합니다. 상태와 동작의 연결, 빠르기는 이미지 펫과 같습니다.
- **눈**: 대기 중에는 커서를 16방향이 아니라 끊김 없이 따라갑니다. 커서가 가까우면 조금만, 멀면 끝까지 돌아갑니다.
- **색**: 펫 꾸미기 창의 "색상"에서 몸 색을 바꿉니다. 음영은 그대로 두고 색만 옮기며, 어두운 색을 고르면 눈이 밝은 색으로 바뀝니다. 고른 색은 PC마다 저장됩니다.
- **그리는 횟수**: 평소 초당 30장, 눈이 움직이거나 끌거나 한 번 재생하는 동작 중에는 60장입니다. `config.js`의 `FPS_3D_IDLE`, `FPS_3D_BUSY`로 바꿉니다.
- **GPU**: 3D 펫을 고른 채로 시작할 때만 GPU 가속을 켭니다. 그래서 이미지 펫과 3D 펫 사이를 오가면 프로그램이 다시 뜹니다. 이미지 펫을 쓰는 동안 펫 꾸미기 창의 3D 미리보기는 GPU 없이 그립니다. 이때는 초당 30장으로 낮춰 그리고, 창에 3D 펫을 띄워 둔 동안만 CPU를 더 씁니다(코어 1개의 25~50%쯤).
- **그리지 못할 때**: 3D를 못 쓰는 PC이거나 그리는 중 오류가 나면 로그에 사유를 남기고 이미지 펫(모찌)으로 바꿔 보여 줍니다. 저장된 선택은 그대로 두므로 다음 실행 때 다시 시도합니다.
- **끄기**: `config.js`의 `DISABLE_GPU`를 `true`로 바꾸면 GPU 가속을 쓰지 않고 3D 펫이 목록에서 빠집니다.

3D 펫 자료는 `node tools/pet3d/build.js`로 다시 만듭니다. 이미지 펫 `orange-pickle`의 시트를 읽어 `pets/orange-pickle-3d/`에 `pet.json`, `model.json`(몸 모양과 동작별 자세), `matcap.png`(색 지도)를 씁니다. `--report=폴더`를 붙이면 동작별로 원본과 3D를 나란히 놓은 확인 그림을 저장합니다. 다른 모양의 캐릭터에는 쓸 수 없습니다(몸이 덩어리 하나이고 눈이 두 개인 캐릭터 전용).

## 훅

펫은 두 가지를 읽습니다.

1. **세션 기록**(`~/.claude/projects/*/*.jsonl`): 지금 쓰는 도구, 세션 제목, 턴 종료. 읽기만 합니다.
2. **훅 이벤트**: 승인 대기처럼 기록만으로는 알 수 없는 신호.

훅은 전역 설정(`~/.claude/settings.json`)에 등록합니다. 펫이 시작할 때 훅이 없거나 깨져 있으면(예: 실행 파일 폴더를 옮김) 스스로 다시 등록합니다. 메뉴에서 껐으면 다시 등록하지 않습니다.

- 펫이 등록하는 훅은 펫 실행 파일 자신을 `--claude-pet-hook` 인자로 부릅니다. 그래서 Node.js가 없는 PC에서도 동작합니다. 이벤트 한 줄만 기록하고 0.2초 안에 끝납니다.
- 등록하는 이벤트: `Stop`, `StopFailure`, `PermissionRequest`, `Notification`, `Elicitation`, `ElicitationResult`, `SessionEnd`. 윈도우의 Electron은 시작할 때 빈 줄을 출력하는데, `UserPromptSubmit` 훅의 출력은 Claude의 입력에 섞이므로 이 이벤트에는 등록하지 않습니다. 턴 시작은 세션 기록으로 압니다.
- 도구 호출마다 도는 이벤트에는 등록하지 않습니다.
- 다른 도구가 등록한 훅은 건드리지 않고, 바꾸기 전 설정을 `settings.json.claude-pet-backup-날짜`로 남깁니다.
- 예전 방식(Node.js로 `hook-event.js` 사본을 부르는 훅)도 그대로 동작합니다. 이 폴더에서 `node install-hooks.js`(등록), `--status`(확인), `--uninstall`(제거)로 다룰 수 있습니다. 이미 이 방식으로 등록돼 있고 멀쩡하면 펫이 바꾸지 않습니다.
- 훅 없이도 동작하지만, 승인 대기를 정확히 알 수 없습니다.

## 펫 추가하기

펫 하나는 폴더 하나입니다.

```
my-pet/
  pet.json           id, displayName, description, spritesheetPath, kind, spriteVersionNumber
  spritesheet.webp   가로 8칸, 한 칸 192x208. 9행(1536x1872) 또는 11행(1536x2288)
```

보통은 펫 꾸미기 창의 "압축 파일에서 펫 추가"로 넣습니다. 가져온 펫은 `~/.claude-pet/pets/`에 들어갑니다. 압축 파일에서는 `pet.json`과 시트 그림(`spritesheet.webp`/`.png`)만 꺼내고, `pet.json`은 이름·설명 같은 허용한 항목만 남겨 다시 씁니다. 실행 파일 같은 다른 파일, 폴더 밖을 가리키는 경로, 40MB가 넘는 파일, 크게 풀리는 항목(압축 폭탄)은 받지 않습니다. 3D 펫은 가져올 수 없습니다.

이 폴더의 `pets/`에는 함께 나가는 펫이 있습니다: **모찌 3D**(기본 펫)와 **모찌** 이미지판. 모찌 이미지판은 `pet.json`의 `"hidden": true`로 목록에서 숨겨 두었고, 3D를 그리지 못하는 PC에서만 대신 뜹니다. `pet.json`에 `"displayNames": { "ko": "…", "en": "…" }`를 두면 언어마다 다른 이름을 씁니다.

코덱스 펫 폴더 `~/.codex/pets/`(`CODEX_HOME`이 있으면 그 아래)는 기본으로 읽지 않습니다. 코덱스 펫도 목록에 넣으려면 `config.js`의 `INCLUDE_CODEX_PETS`를 `true`로 바꿉니다. 켜도 읽기만 합니다.

폴더를 넣은 뒤 펫 꾸미기 창에서 "새로 고침"을 누르세요. 규격에 맞지 않는 펫은 고를 수 없고, 목록에 "불러올 수 없음"으로 나옵니다. 사유는 그 카드를 누르면 보이고 로그에도 남습니다.

## PC별 데이터

`~/.claude-pet/`에 있으며 동기화되지 않습니다.

| 항목 | 내용 |
|---|---|
| `runtime/` | Electron |
| `state.json` | 펫 위치, 선택한 펫, 크기 배율, 3D 펫의 색, 말풍선·알림음 설정, 화면 언어, 훅 켬/끔, 처음 실행 창을 보았는지 |
| `pets/` | 압축 파일로 가져온 펫 |
| `events.jsonl` | 훅 이벤트 (2MB를 넘으면 비움) |
| `hook-event.js` | 훅 스크립트 사본 (예전 방식으로 등록했을 때만) |
| `pet.log` | 로그 (1MB를 넘으면 비움) |
| `dist/`, `build-cache/` | 배포 묶음과 맥용 Electron (`tools/package.js`를 돌렸을 때만) |

## 지우는 법

1. 우클릭 메뉴에서 "승인 대기 알림 (훅)"과 "컴퓨터 켤 때 자동 실행"을 끕니다.
2. 펫을 우클릭해 종료합니다.
3. 프로그램 폴더와 `~/.claude-pet/` 폴더를 지웁니다.

## 알아 둘 점

- Claude Code 세션(데스크톱 앱 Code 탭, CLI, IDE 확장)만 보여 줍니다. 일반 채팅 탭은 PC에 진행 기록이 남지 않아 볼 수 없습니다.
- 승인한 뒤 오래 걸리는 도구는 결과가 나올 때까지 "확인 필요"로 남습니다. 승인 순간을 알려 주는 훅이 없기 때문입니다.
- 완료·오류 표시는 Claude 앱에서 그 세션을 직접 열어 보면 펫을 누르지 않아도 풀립니다. Claude 앱이 세션 파일에 남기는 "마지막으로 화면에 띄운 시각"이 작업이 끝난 시각보다 뒤인지를 봅니다. 그래서 다른 세션이나 다른 프로그램을 보다가 그 세션을 열었을 때, 최소화했거나 완전히 가려져 있던 Claude 창을 다시 띄웠을 때 풀립니다. 작업이 끝나는 순간 이미 그 세션을 보고 있었거나 Claude 창이 계속 화면에 보이던 경우에는 앱이 새 기록을 남기지 않아 풀리지 않습니다. Claude 데스크톱 앱에서 만든 세션에만 해당하고, `config.js`의 `SEEN_IN_APP`으로 끌 수 있습니다.
- 펫을 켜기 전부터 진행 중이던 턴은 경과 시간이 실제보다 짧게 나옵니다.
- 메모리는 윈도우에서 프로세스 합계 300~400MB를 씁니다 (작업 관리자의 작업 집합 기준 실측). 3D 펫도 시작 직후 350MB로 비슷했습니다.
- CPU는 이미지 펫이 코어 1개의 1~2%, 3D 펫이 9%쯤입니다 (RTX 3060 PC에서 30초 평균 실측). 3D 펫은 초당 그리는 횟수를 낮추면 줄어듭니다.
- 맥에서는 아직 실행해 보지 않았습니다. 3D 펫, 맥 배포 묶음, 맥에서 훅이 Electron을 부를 때 Dock 아이콘이 잠깐 튀는지도 확인하지 못했습니다.
- 영어 화면에서도 세션 제목처럼 사용자가 쓴 글은 그대로 보입니다. 규격에 맞지 않는 펫의 자세한 사유는 한국어로만 로그에 남습니다.
- 3D 펫의 가장자리는 원본 그림보다 또렷하고, 노트북의 키보드 무늬 같은 세부는 원본과 조금 다릅니다.
- 어떤 상황에 어떤 행을 재생할지는 코덱스 공식 문서에 없어 행 설명을 보고 정했습니다. v2 규격(11행, 바라보기 16방향)은 codex-pets.net의 사이트 코드와 실제 펫 파일에서 확인한 내용입니다.
